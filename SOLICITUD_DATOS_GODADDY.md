# 📋 SOLICITUD DE DATOS - GODADDY

**Para conectar SHORTLIST.GT con tu servidor de Godaddy**

---

## ¿QUÉ NECESITAMOS?

Para que puedas guardar tus datos de empresa en Godaddy (además de Supabase), necesito que me proporcionas los siguientes datos:

---

## 📌 DATOS 1: INFORMACIÓN DE LA BASE DE DATOS

**¿Dónde encontrarlo?** En tu panel de Godaddy → cPanel → MySQL Databases

```
□ HOST/SERVIDOR
  Ejemplo: mysql123.godaddy.com
  
□ USUARIO DE BASE DE DATOS
  Ejemplo: empresa_user
  
□ CONTRASEÑA DE BASE DE DATOS
  Ejemplo: ••••••••••
  
□ NOMBRE DE LA BASE DE DATOS
  Ejemplo: empresa_db
  
□ PUERTO (generalmente es 3306, no cambies si no sabes)
  Ejemplo: 3306
```

---

## 📌 DATOS 2: INFORMACIÓN DE FTP/SSH

**¿Dónde encontrarlo?** En tu panel de Godaddy → cPanel → FTP Accounts o SSH Access

```
□ HOST FTP/SSH
  Ejemplo: ftp.tudominio.com
  o: tudominio.com
  
□ USUARIO FTP/SSH
  Ejemplo: empresa_ftp
  
□ CONTRASEÑA FTP/SSH
  Ejemplo: ••••••••••
  
□ PUERTO SSH (generalmente 22)
  Ejemplo: 22
```

---

## 📌 DATOS 3: INFORMACIÓN DEL DOMINIO

```
□ DOMINIO
  Ejemplo: tuempresa.com
  
□ TIPO DE SERVIDOR
  ¿Es Linux o Windows?
  
□ PHP VERSION (si es Linux)
  Ejemplo: PHP 7.4 o 8.1
```

---

## ❓ PREGUNTAS FRECUENTES

**P: ¿Por qué necesitas esto?**
R: Para conectar SHORTLIST.GT con tu servidor de Godaddy y guardar los datos de tu empresa (perfil, configuración, licencia) en tu propio servidor, además de Supabase.

**P: ¿Es seguro dar esta información?**
R: Sí, necesito estos datos para la conexión técnica. Solo se usarán para guardar tus datos.

**P: ¿Qué datos se guardarán donde?**
R: 
- **Supabase** (en la nube): Candidatos, Vacantes, Evaluaciones
- **Godaddy** (tu servidor): Perfil de empresa, Configuración, Licencia

**P: ¿Pierdo mis datos si cambio esto?**
R: No, tus datos actuales se mantienen intactos.

## 📞 SI NO ENCUENTRAN LOS DATOS

El cliente puede:
1. Contactar al **Soporte de Godaddy** (chat en vivo en godaddy.com)
2. Decirles: *"Necesito las credenciales de MySQL y FTP para mi aplicación web"*
3. El soporte les proporciona todo en 5 minutos
